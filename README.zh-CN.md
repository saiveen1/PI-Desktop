# PI-Desktop · 个人版

> **当前发布线：0.22.x（beta）。**

独立维护的本地优先 AI Agent 工作台，重点投入**执行框架加固、多 Agent 协作和日常使用体验**。

本版本基于[上游 PI-Desktop](https://github.com/vastsa/PI-Desktop)，会持续跟进上游更新，
在保留本地功能与修复的基础上评估、合并适用改动；功能与发布节奏独立演进。

## 本版本新增、加固与关键修复

以下介绍的是**在上游基础上的本地增量**，不是上游功能目录。内容对应当前源码，可能晚于
[已记录版本](CHANGELOG.md)。[改动来源说明](docs/maintenance/personal-edition-provenance.md)
记录了对照版本、原始提交、实现依据及排除的上游功能。
部分新流程仍需更广泛的集成验证；beta 不代表稳定性或安装升级已经得到保证。

### Harness 加固：让执行、工具调用与恢复有明确边界

Harness 指控制 Agent 执行、工具调用和恢复的框架。本版本在既有框架上加固，而不是另起一套。

- **扩展重复失败保护**：在既有 Edit／补丁保护之外，覆盖 Write 和相同 Bash 命令的重复同类失败。
  实际修改文件后允许重新验证；拿到完整的新上下文时保留有限恢复机会。
  Host 容量拒绝单独计数，不再当成补丁写错。
- **先检查准入，再执行**：后台命令先预约容量再启动进程，落实单会话 shell 数量限制，
  并为完成／取消操作保留 Host 处理容量。审批等待不再消耗工具请求的整体截止时间，
  实际执行期限仍然有效。
- **工具参数更容易纠正**：兼容带 tag 或空 ops 的受支持旧式 Edit 替换参数，明确指出冲突插入位置，
  修正后台等待／停止时的任务选择；不放宽文件版本、已读上下文和授权校验。
- **有限纠正，减少无声停工**：主 Agent 把工具调用写成普通文本时，每个用户轮次最多提示纠正一次，
  不直接执行这段文本。另有可关闭的未完成清单续跑机制，可对当前轮次的未完工作额外续跑一次。
  两者可能增加模型用量，不保证一定完成。
- **退化输出保护**：检测并中断特定的长串空白／符号堆积型输出，保留已有结果，不自动重放；
  大段输出采用有上限的预览。这不是对所有重复文句或低质量回答的通用检测。
- **等待与上下文由运行时控制**：主会话模型请求可配置连接空闲策略，不再把每次输出停顿都当作
  需要重放的请求；触发本地空闲截止后由用户决定重试。上下文压缩不再通过模型工具主动触发，
  保留既有的自动压缩与用户 `/compact` 入口。
- **压缩后延续执行进度**：主会话活动任务的检查点除了摘要，还保留当前请求、预算内的近期进展和成对的
  工具调用／结果，重启后也能恢复，不再只靠摘要记住刚做过什么。长结果的摘要输入保留两端，
  并标明未纳入视觉内容的图片；续接提示区分已完成、待完成及结果未知的操作。
  已结束任务不会重新带回旧请求。这能减少上下文丢失，但不保证模型永不重复或外部操作恰好执行一次。

### 子代理协作：调度、审批、跟进与恢复

- **统一模型池与审批**：增加分组模型审批、可恢复的审批入口、策略热更新，以及会话级候选模型池
  和审批覆盖设置；按需提供模型描述以便按任务选择，可配置的失败处理仍受模型授权约束。
- **会话与全局任务索引**：从聊天顶部打开当前会话的子代理，或查看跨项目委派历史与保留的审批结果。
  历史审批记录不代表再次执行的授权。
- **进展检查点与直接跟进**：在既有恢复机制上补充自动保存的本地检查点和可配置运行预算。
  本地 Agent 会话中可向运行中的子代理补充指令，或显式恢复已结束任务；查看历史不会重启任务。
- **更准确的交付与恢复判定**：不把旧进度文字或截断结尾当成最终报告，合并重复恢复请求，
  支持在下一次用户输入时接回此前被父任务失败打断的工作。
  固定工具子代理也能加载已提供的技能，无需同时继承无关的插件／MCP 执行工具。

### 会话组织与通知

- **项目内分组、彩色标签与可控排序**：分组决定摆放位置，多标签不会重复生成会话条目。
  手动移动和已接受的用户发送会更新活动顺序；只是打开聊天或接收流式输出不会改变顺序。
- **显式勾选与可恢复删除**：在原有快捷键多选基础上增加勾选框、选择操作和批量归档／取消归档。
  本地 Desktop 会话增加回收站、恢复及需单独确认的永久删除；不覆盖原生 Pi 与远程会话。
- **统一核心通知策略**：审批、提问、失败和完成共用渠道／声音设置，待处理操作与历史记录分开。
  通知带你回到相关入口，不会替你批准或重启任务。

### 聊天、文件与图片体验

- **任务优先的阅读方式**：活动与思考默认折叠，用紧凑任务列表和失败摘要呈现过程，复用主／子任务
  详情展示；运行中、已停止或失败时，也能查看已记录的文件改动。
- **扩展聊天文件操作**：增加另存为、支持的文本内容复制，将“打开方式”从 HTML 扩展到普通文件的
  默认应用。
- **工具图片连续可用**：增加通用工具图片图库，保留历史预览，将相邻成功的图片读取分组展示；
  修复图片在后续请求和子代理模型上下文中的保留与传递，模型能力或图片限制阻止传递时明确提示。

### 日常使用中的关键修复

- **修复多 Agent 并发下的文件工具连锁阻塞**：解决长时间搜索持有 Host 范围的文件锁，导致其他会话
  读写连续准入超时、多个代理无法修改文件的问题。改为逐文件协调，并补齐取消与资源释放处理，
  同时保留同一文件的读写保护。
- **阅读恢复尊重新导航**：修复切换会话和延迟历史读取的竞态，避免旧恢复结果覆盖新的阅读意图，
  或丢掉已经加载的历史范围。
- **执行结果更清楚**：区分失败、拒绝、跳过、中断和需要补充上下文，保留阶段／重试诊断，
  清理陈旧的运行中标记和重试提示；同时修复重命名输入反复全选、折叠审批入口干扰输入框的问题。
- **针对性的 Windows 与路径修复**：让裸文件名沿用 Markdown 中明确给出的目录，
  在 worktree 路径映射前规范化引用；未继承编码偏好时，将执行器子进程的 Python 标准流默认设为 UTF-8。
- **数据目录迁移兼容**：修复 Windows 路径写法变化导致项目级能力开关覆盖设置失效的问题，
  并在迁移时重映射本地会话组织数据的项目路径；沿用既有迁移流程。

## 从源码运行

需要 Node.js `>=22.19`、pnpm `>=10` 和稳定的 Rust 工具链；Windows 还需 MSVC Build Tools。
在源码目录执行：

```bash
pnpm install
pnpm dev
```

本版本的 `pnpm dev` 默认清除继承的数据目录覆盖设置，不要让它使用正在运行的安装版配置目录。
检查命令与显式复用数据的规则见[开发流程](docs/spec/06-delivery/03-ai-development-workflow.md)。

Windows 可使用 [start-local.cmd](start-local.cmd) 打开源码启动控制台，无需打包或安装。
这是**显式使用已有配置目录**的入口：先配置被 Git 忽略的 `start-local.data-dir.local`，
停止所有使用该目录的进程，并完成离线备份。启动器会要求确认，但不会替你备份或停止进程。
使用前请阅读[启动器说明](docs/spec/06-delivery/03-ai-development-workflow.md#windows-local-source-launcher)；
`start-local.cmd -CheckOnly` 仅检查前置条件，不启动应用。

## 个人 Windows 构建

个人打包流程面向 **Windows 10/11 x64**，生成禁用官方自动更新的 NSIS 安装包。
每次构建都附带唯一标识、源码元数据、从 Git 历史生成的变更说明和 SHA-256 校验值。
构建清理只处理临时产物，不删除以往安装包。

```bash
pnpm dist:personal --check  # 预览构建计划，不执行构建
pnpm dist:personal          # 构建，不改变应用版本
```

产物位于 `apps/desktop/release/personal/`。**打包不会安装或启动应用。**
候选版本发布、验证范围和产物详情见[个人发布说明](docs/spec/06-delivery/07-personal-release-runbook.md)。

### 使用 GitHub Actions 构建

个人 fork 的 [Personal Windows 工作流](.github/workflows/personal-windows.yml)
在代码推送到 `main` 后构建，不自动修改版本号；成功运行的安装包与溯源文件作为 Actions
产物保留 30 天，可在对应运行页面下载。
需要新 beta 时，在 `main` 上点击 **Run workflow**，明确填写更高的 `release_version`；
留空则只构建。手动发布成功后会保存版本／历史文件，并在自己的 fork 创建 `personal-v`
预发布版本，不会开启已安装应用的自动更新。初次配置、权限和失败恢复说明见
[Actions 发布说明](docs/spec/06-delivery/07-personal-release-runbook.md#github-actions-personal-fork-only)。
